기기에서 처리하는 정보

  • 배터리 잔량, 충전 상태, 전류, 전압과 배터리 온도
  • Android가 제공하는 기기 온도 상태와 온도 여유도
  • 사용 가능한 메모리와 앱 데이터 저장공간
  • 사용자가 실행한 비교 진단의 최신 결과

저장과 전송

최신 완료 기록은 앱의 로컬 저장소에 보관됩니다. WHYMETRIC 운영 서버로 진단 측정값이나 기록을 전송하지 않습니다.

광고 서비스

완료된 진단 기록 아래의 배너 광고를 위해 Google AdMob과 User Messaging Platform을 사용합니다.

  • Google Mobile Ads SDK는 IP 주소, 광고 ID 또는 앱 세트 ID를 처리할 수 있습니다.
  • 광고 노출·클릭 같은 상호작용과 SDK 진단 정보가 처리될 수 있습니다.
  • WHYMETRIC은 진단 측정값과 광고 식별자를 결합하지 않습니다.

광고가 표시되지 않는 화면

첫 실행, 실시간 진단, 증상 선택, 진단 진행 중, 온도 경고, 빈 기록과 개인정보 안내 화면에는 광고를 표시하지 않습니다.

사용자의 선택과 삭제

  • 앱 데이터 삭제 또는 앱 제거로 로컬 진단 기록을 삭제할 수 있습니다.
  • Android 설정에서 광고 ID를 재설정하거나 삭제할 수 있습니다.
